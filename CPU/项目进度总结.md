## 项目目标

使用深度学习加速Inamuro两相流LBM模拟，通过神经网络预测压力场初值，减少压力泊松方程的迭代次数，从而提升整体计算效率。

#### v3模型（预测Δp，Step 11-2999训练）—— 当前最新版本 ✅

**模型架构**：3D U-Net（6通道输入 → Δp）
- 输入：[ρ, u, v, w, φ, p_prev]，shape (6, 48, 96, 128)
- 输出：Δp = p_current - p_prev，shape (1, 48, 96, 128)
- 参数量：1.4M，base_features=32

**训练配置**：
- 数据范围：Step 11-2999（去掉前10步极端样本，去掉3000步后稳态数据）
- 数据划分：训练2391，验证298，测试300（80/10/10）
- 加权采样：按 sqrt(|Δp|_max) 加权，平衡动态/稳态分布
- 损失函数：Huber Loss + 0.1×梯度损失
- 优化器：Adam (lr=5e-4)，CosineAnnealingLR
- epochs：100，batch_size=4

### ✅ 4. 模型集成到LBM求解器（3月完成）

#### 4.1 自适应切换策略

**核心设计**：根据上一步迭代次数决定是否使用NN
```cpp
// 迭代次数 > 100 → 动态阶段 → 使用NN预测Δp
// 迭代次数 ≤ 100 → 稳态阶段 → 直接用p_prev
bool use_nn = use_neural_network && model_loaded && (last_iteration_count > NN_ITER_THRESHOLD);
```

**阈值**：`NN_ITER_THRESHOLD = 100`

#### 4.2 推理流程

```
输入物理场 [ρ, u, v, w, φ, p_prev]
    ↓
z-score归一化（6通道）
    ↓
GPU推理（~80ms）
    ↓
反归一化得到 Δp
    ↓
p_new = p_prev + Δp
    ↓
迭代求解（收敛阈值：0.001，每10步检查）
```

#### 4.3 关键参数

```cpp
// Inamuro.hpp
const std::vector<double> input_means = {2.51422158, -0.00001289, 0.0, 0.0, 0.01392343, -0.02551287};
const std::vector<double> input_stds  = {8.23543629, 0.00389878, 0.00401780, 0.00503228, 0.01414641, 0.00920020};
const double output_mean = -8.3591e-06;
const double output_std  =  1.3666e-04;
static constexpr int NN_ITER_THRESHOLD = 100;
```

## 二、技术实现细节

### 2.1 核心创新点

**传统方法的问题**：
- 使用前一时刻压力作为初值
- 在动态阶段，压力场变化剧烈，初值误差大
- 需要大量迭代才能收敛

**NN加速方法的优势**：
- 预测压力增量Δp而非绝对压力，学习目标更稳定
- 加入p_prev作为第6个输入通道，提供时序信息
- 自适应切换策略，只在需要时使用NN

### 2.2 关键技术挑战及解决方案

#### 挑战1：v1模型预测绝对压力导致NaN
**解决方案**：改为预测Δp = p_current - p_prev
- Δp量级小，模型更容易学习
- 即使预测不准，p_prev + Δp也不会偏离太远

#### 挑战2：归一化参数错误（差14倍）
**解决方案**：重新计算体素级全局统计值
- 用Welford在线算法处理全量数据
- output_std从0.001185修正为1.3666e-04

#### 挑战3：数据不平衡（稳态占76%）
**解决方案**：
- 只用Step 11-2999训练（动态+过渡阶段）
- WeightedRandomSampler按sqrt(|Δp|_max)加权

#### 挑战4：前10步极端样本（|Δp|_max达18000σ）
**解决方案**：去掉Step 1-10，从Step 11开始训练

#### 挑战5：稳态阶段NN反而变差
**解决方案**：自适应切换，迭代次数≤100时跳过NN

### 2.3 v1 vs v3 对比

| 对比项 | v1（直接预测p） | v3（预测Δp） |
|--------|--------------|------------|
| 输入通道 | 5（ρ,u,v,w,φ） | 6（+p_prev） |
| 输出 | 绝对压力p | 压力增量Δp |
| 归一化 | 错误（差14倍） | 正确（体素级统计） |
| 训练数据 | Step 0-1524 | Step 11-2999 |
| 加权采样 | 无 | sqrt(|Δp|_max) |
| NaN问题 | 有 | 无 |
| 实测加速比 | -15%（反而更慢） | **+47%** |

## 五、关键经验总结

### 5.1 成功经验

1. **预测增量而非绝对值**：Δp比p更容易学习，且天然稳定
2. **正确的归一化**：体素级统计比样本级统计更准确
3. **数据范围选择**：只用动态阶段数据，避免稳态数据稀释信号
4. **自适应切换**：不是所有步骤都需要NN，按需使用才能最大化收益
5. **GPU推理**：~80ms推理时间可忽略不计

### 5.2 失败教训

1. **v1直接预测p**：峰值偏大2-3倍，导致NaN，整体反而变慢
2. **归一化参数错误**：output_std差14倍，导致训练信号被压扁
3. **全量数据训练**：稳态数据占76%，严重稀释动态阶段的学习信号

### 5.3 局限性

1. **不稳定区（Step 14-18）**：NN预测偏差，加速比<1
2. **模型泛化能力**：仅在当前参数配置下验证
3. **GPU依赖**：CPU推理太慢（28s），需要CUDA支持

### 5.4 未来改进方向

1. **改善不稳定区**：针对Step 14-18的数据分布做专项优化
2. **更细粒度的自适应策略**：不仅基于迭代次数，还可基于压力场变化率
3. **泛化能力验证**：在不同参数（液滴大小、密度比等）下测试
4. **模型压缩**：减小模型大小，进一步降低推理时间
